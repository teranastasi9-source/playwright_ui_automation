QA Playground

A small, self-contained set of pages used by playwright_ui_automation's own test suite to demonstrate generic UI-testing patterns (alerts, tables, dropdowns, hover menus, new tabs, file upload/download, locator strategies, AJAX) without depending on third-party demo sites for them. Served locally by the test suite itself - see tests/conftest.py.

These pages are plain static HTML/CSS/JS generated with Claude Code for this specific testing purpose - built to replicate the exact markup the existing tests already relied on, not hand-written from scratch.
